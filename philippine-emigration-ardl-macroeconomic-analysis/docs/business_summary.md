# Business / Policy Summary

This project studies the macroeconomic determinants of Philippine emigration using annual data and ARDL-style time-series modeling.

## Decision relevance

Migration is affected by both domestic conditions and destination-country conditions. This project frames emigration as a measurable macroeconomic outcome that can be analyzed with GDP, labor share, consumption share, and exchange-rate indicators.

## Main analytical value

- Quantifies short-run and long-run relationships using ARDL and ECM workflows.
- Uses diagnostics to test model reliability.
- Produces visual artifacts for trend, residual, and stability analysis.
- Supports policy discussion around labor mobility, external opportunities, and macroeconomic push-pull factors.

## Portfolio positioning

This is strongest for roles involving economics, policy analytics, development research, econometrics, migration analytics, and quantitative social science.
