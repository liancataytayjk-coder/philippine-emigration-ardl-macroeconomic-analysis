# Data Dictionary

| Variable | Description |
|---|---|
| `year` | Annual observation year |
| `emig` | Philippine emigrant count |
| `ph_gdp` | Philippine GDP per capita |
| `ph_labsh` | Philippine labor share |
| `ph_csg` | Philippine consumption share |
| `us_gdp` | U.S. GDP per capita |
| `us_labsh` | U.S. labor share |
| `us_csg` | U.S. consumption share |
| `exc` | PHP/USD exchange rate |

Derived variables in the Stata workflow include log transformations and first differences for ARDL and ECM modeling.
